# Skole – timer gått i fag

En enkel nettside som viser hvor mange prosent av timene i hvert fag som er gått dette skoleåret.

- Timeplan med tider, rom og lærer
- Skolerute for Porsgrunn vgs 2026/27 (ferier og fridager)
- Årstimer per fag fra læreplanen
- Teller hver time som gjennomført når den er ferdig

Alt ligger i `index.html`. Endringer du gjør på siden lagres i nettleseren din.

## Publisering

Settings → Pages → Source: «Deploy from a branch», Branch: `main`, mappe `/ (root)`.
